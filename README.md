# Три в ряд — ИИ против ИИ

Браузерная игра «три в ряд» (match-3), в которой друг против друга играют два ИИ.
Без зависимостей и сборки: просто откройте `index.html` в браузере.

## Особенности

- Поле 8×8, **6 видов камней**: рубин (круг), янтарь (квадрат), топаз (звезда),
  изумруд (ромб), сапфир (шестиугольник), аметист (треугольник).
- **Анимации**:
  - *свап* — камни меняются местами по дуге, со шлейфом искр и масштабированием;
  - *исчезновение* — вспышка и увеличение, затем сжатие с вращением, взрыв частиц и ударная волна;
  - *падение* — ускоряющееся падение с растяжением и сплющиванием при приземлении;
  - *появление* — новые камни плавно проявляются сверху; в начале партии поле «ссыпается» волной;
  - перемешивание при отсутствии ходов, всплывающие очки, баннеры «Комбо ×N!».
- **Два ИИ**:
  - **Нова (Жадный)** — выбирает ход с максимальными очками прямо сейчас (с учётом каскадов);
  - **Орион (Стратег)** — смотрит на ход вперёд: своя выгода минус лучший ответ соперника.
- По 20 ходов каждому; после партии новая начинается автоматически.
- Управление: пауза (кнопка или пробел), скорость 0.5×–4×, перезапуск.

## Очки

10 за каждый камень, +20 за линию из 4, +60 за линию из 5+; каскады умножают очки на номер комбо.
